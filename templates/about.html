About Krushi

A smart crop recommendation and agricultural guidance system designed to make data-driven farming decisions accessible to everyone.

What is Krushi?

Krushi is a crop recommendation system built as an MCA final-year project. It uses a machine learning classification model trained on soil and climate data to recommend the most suitable crop for a given set of field conditions.

The idea behind this project is straightforward: farmers and agriculture students often struggle with choosing the right crop for their soil. By inputting simple measurable values like nitrogen, phosphorus, potassium, temperature, humidity, pH, and rainfall, the system can suggest a crop that is most likely to perform well.

Prediction-Based Uses a trained ML model to map field inputs to 22 supported crop outcomes.
Easy to Use Simple 7-field form with immediate results and practical growing tips.
Farming Assistant KrushiBot answers general questions on soil, irrigation, pests, and seasons.
Indian Context Focused on crops and soil parameters widely relevant to Indian agriculture.

Inputs Used by the Model
  • Nitrogen (N) — Soil nutrient content ratio
  • Phosphorus (P) — Soil nutrient content ratio
  • Potassium (K) — Soil nutrient content ratio
  • Temperature (°C) — Local average temperature
  • Humidity (%) — Relative humidity in the area
  • pH Value — Soil acidity/alkalinity level
  • Rainfall (mm) — Total annual rainfall
Crops Supported

The trained model predicts across 22 different crops: Rice, Maize, Jute, Cotton, Coconut, Papaya, Orange, Apple, Muskmelon, Watermelon, Grapes, Mango, Banana, Pomegranate, Lentil, Blackgram, Mungbean, Mothbeans, Pigeonpeas, Kidneybeans, Chickpea, and Coffee.
